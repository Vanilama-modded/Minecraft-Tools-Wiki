> ## Adding a site
> You can add a site using this schema
> ```json
>{
>        "tool": "Category",
>        "links": [
>            {
>                "url": "https://example.com/1",
>                "name": "Example 1",
>                "tooltip": "Tooltip 1"
>            },
>            {
>                "url": "https://example.com/2",
>                "name": "Example 2",
>                "tooltip": "Tooltip 2"
>            }
>        ]
>    },
> ```
>in [tools.json](/tools.json)
